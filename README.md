# 📝 Python To-Do List

A simple command-line To-Do List application built using Python.

## Features

- View Tasks
- Add Tasks
- Delete Tasks
- Saves tasks in a text file

## Requirements

- Python 3.x

## Run

```bash
python todo.py
```
